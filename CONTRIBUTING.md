# Contributing

1. Read [`docs/HANDOFF.md`](docs/HANDOFF.md).
2. Put your name next to a milestone in section 11 and push that first, so two people don't build the same thing.
3. Work on a branch, run `npm test` and `npm run build`, then open a pull request.
4. Tick the milestone checkbox in `docs/HANDOFF.md` in the same pull request.
